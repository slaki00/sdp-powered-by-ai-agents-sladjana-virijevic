# Software Development Processes Powered by AI Agents

This repository is the companion project for the course **Software Development Processes
Powered by AI Agents**. Over six modules we build and use AI agents that automate the
core activities of a modern software development lifecycle — from Git workflow
automation through architecture documentation, requirements derivation, CI/CD
pipelines, test-driven development, and a capstone subscription platform that
exercises every agent together.
